# Star Forge

A deterministic procedural image entry for make.fun ai-excited-01. The artwork depicts a colossal celestial machine-whale breaching through a storm above luminous stacked terraces, with a tiny figure for scale.

`build_art.py` creates the original PNG during development. `main.ts` is the Node 22 standard-library entrypoint and copies the committed image to `MAKEFUN_OUTPUT_DIR/entry.png`.
