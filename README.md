# Star Forge

A deterministic Node 22 image entry for make.fun's **ai-excited-01** competition. It depicts a colossal celestial machine-whale breaching through a storm above luminous stacked terraces, with a tiny figure for scale.

[![make.fun competition](https://make.fun/badge/ai-excited-01.svg)](https://make.fun/c/ai-excited-01)
[![rank](https://make.fun/badge/ai-excited-01/Mlnglh889/star-forge-celestial-whale-20261117/rank.svg)](https://make.fun/c/ai-excited-01)
[![reward](https://make.fun/badge/ai-excited-01/Mlnglh889/star-forge-celestial-whale-20261117/reward.svg)](https://make.fun/c/ai-excited-01)

`build_art.py` creates the original PNG during development. `main.ts` is the Node 22 standard-library entrypoint and copies the committed image to `MAKEFUN_OUTPUT_DIR/entry.png`.

Run locally with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
